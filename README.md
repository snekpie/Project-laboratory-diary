# Project Laboratory Diary

A collection of notes, diagrams, technical resources, and research findings for my Project Laboratory.

This repository serves as a digital lab notebook where I document what I learn, keep useful references, and organize resources related to my project.

## Contents

* **Notes** — Technical explanations, research findings, and learning notes.
* **Figures** — Diagrams, illustrations, and other images referenced in the notes.
* **Resources** — Useful documentation, datasheets, and other technical references.

The notes cover topics such as clock domain crossing (CDC), static timing analysis (STA), Verilog, and FPGA development.

## Using the Repository

The notes are written in Markdown and organized as an [Obsidian](https://obsidian.md/) vault.

To use the repository locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/snekpie/Project-laboratory-diary.git
   ```
2. Open Obsidian.
3. Select **Open folder as vault**.
4. Choose the cloned `Project-laboratory-diary` folder.

[Obsidian](https://obsidian.md/) is free to use.

## Keeping Up to Date

The repository uses Git for version control. To download the latest changes, run:

```bash
git pull
```

If you make changes locally and want to save them to the repository:

```bash
git add .
git commit -m "Describe your changes"
git push
```

## Purpose

This repository is a living collection of notes and resources that grows alongside my Project Laboratory work. It helps me keep technical knowledge organized, document progress, and revisit useful information later.
