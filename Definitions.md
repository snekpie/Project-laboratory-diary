Some of the useful and important definitions I've come across in literature, written down in alphabetical order. If deemed necessary, I've put down a hint for what the definition is important for, in the brackets after the definition.

#### D
**DNL - Differential Nonlinearity.** It is a commonly used measure of performance in DACs and ADCs. It is a term describing the deviation between two analog values corresponding to adjacent input digital values. Accuracy of DAC is mainly determined by this specification. Any two adjacent digital codes correspond to output analog voltages that are exactly one LSB apart.

#### I
**INL - Integral Nonlinearity.** Commonly used measure of performance in DAC and ADC converters. In DACs, it is a measure of deviation between the ideal output value and the actual measured output value for a certain input code. In ADCs, it is the deviation between the ideal input threshold value and the measured threshold level of a certain output code. The ideal transfer function of a DAC or ADC is a straight line.![[DAC ADC INL graph.png]]

#### R
**Resolution** denotes the minimum measurable time interval, while practical measurement precision is typically characterized by the standard deviation of repeated time-interval measurements.
